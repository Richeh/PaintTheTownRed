Town Red Privacy Policy

Last updated: 20 August 2026

Town Red is a collaborative mapping tool that lets people paint preference areas and share map annotations while browsing property maps.

Information Town Red processes

Town Red uses Supabase to provide authentication, sharing and synchronisation. For Chrome Web Store disclosure purposes, Town Red processes the following categories of user data:

  • Personally identifiable information: the display name you choose for your Town Red profile. This may be a nickname or pseudonym and Town Red does not require your legal name.
  • Authentication information: Supabase authentication identifiers and session credentials used to keep you signed in and enforce access to shared maps.
  • Location: geographic coordinates deliberately created as part of Town Red content, including painted areas and map points. Town Red does not request or collect the device's GPS location.

Town Red also processes shared-map membership and role information; paint strokes; map points and their labels; invite tokens and invite usage information; and timestamps associated with this data.

The Chrome extension stores local settings, cached overlay data and authentication session information in browser storage so that Town Red can remember your session and preferences between visits.

Information Town Red does not collect

Town Red does not collect health information, financial or payment information, personal communications, web browsing history, or general user-activity telemetry such as click, scrolling, mouse-position or keystroke monitoring. It does not collect Rightmove listing text, property descriptions, photographs, hyperlinks or other website content. Pointer input used while painting is processed only to create the geographic Town Red content the user deliberately draws.

How information is used

This information is used only to provide Town Red features: authenticating you, determining which shared maps you may access, synchronising collaborative overlays and annotations, displaying collaborator names, and remembering local preferences.

Sharing

Content you add to a shared Town Red map is visible to other people who have access to that map. Display names may also be visible to collaborators on maps you share. Town Red does not sell personal information or use Town Red data for advertising, creditworthiness, profiling, or purposes unrelated to Town Red's collaborative mapping functionality.

Third-party services

Town Red uses Supabase for authentication, database storage and realtime synchronisation. When the Chrome extension is used on Rightmove, it interacts with the Rightmove page only to display and align Town Red overlays with the property map. Town Red does not transmit Rightmove listing content to Supabase.

Data retention and deletion

Shared map content remains stored until it is deleted by an authorised user or the associated map/account is removed. Local browser data can be removed by clearing the extension/site data or uninstalling the extension. Account-level deletion functionality may be added as Town Red's persistent-account features develop.

Security

Town Red uses Supabase Row Level Security and authenticated database access to restrict shared-map data according to each user's map role. The browser client contains only the Supabase publishable key; no Supabase service-role or secret key is included in the extension.
