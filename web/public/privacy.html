Town Red Privacy Policy

Last updated: 19 August 2026

Town Red is a collaborative mapping tool that lets people paint preference areas and share map annotations while browsing property maps.

Information Town Red processes

Town Red uses Supabase to provide authentication, sharing and synchronisation. It may process an anonymous or registered Supabase user identifier; the display name you choose; shared-map membership and role information; paint strokes and their geographic coordinates; map points, labels and geographic coordinates; invite tokens and invite usage information; and timestamps associated with this data.

The Chrome extension also stores local settings, cached overlay data and authentication session information in browser storage so that Town Red can remember your session and preferences between visits.

How information is used

This information is used only to provide Town Red features: authenticating you, determining which shared maps you may access, synchronising collaborative overlays and annotations, displaying collaborator names, and remembering local preferences.

Sharing

Content you add to a shared Town Red map is visible to other people who have access to that map. Display names may also be visible to collaborators on maps you share. Town Red does not sell personal information or use Town Red data for advertising.

Third-party services

Town Red uses Supabase for authentication, database storage and realtime synchronisation. When the Chrome extension is used on Rightmove, it interacts with the Rightmove page only to display and align Town Red overlays with the property map.

Data retention and deletion

Shared map content remains stored until it is deleted by an authorised user or the associated map/account is removed. Local browser data can be removed by clearing the extension/site data or uninstalling the extension. Account-level deletion functionality may be added as Town Red's persistent-account features develop.

Security

Town Red uses Supabase Row Level Security and authenticated database access to restrict shared-map data according to each user's map role. The browser client contains only the Supabase publishable key; no Supabase service-role or secret key is included in the extension.

Contact
